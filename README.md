# Autonomous Competitor Intelligence Radar

An AI-powered competitor monitoring workflow built with n8n.

## Features
- Automated data collection
- AI-powered competitor analysis
- Impact scoring
- Google Sheets reporting
- Gmail alerts
- Zero-cost setup using OpenRouter + Jina AI

## Tech Stack
- n8n
- OpenRouter
- Jina AI
- Google Sheets
- Gmail

## Workflow
Schedule Trigger → HTTP Requests → Merge → AI Agent Analysis → Google Sheets → AI Impact Scoring → IF Node → Gmail Alert
